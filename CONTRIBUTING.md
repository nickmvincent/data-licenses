# Contributing

DataLicenses.org accepts source-backed additions, corrections, glossary edits,
tests, and site improvements through GitHub issues and pull requests.

## Before submitting catalog content

Read the public methodology. A new initiative needs:

- a canonical public page;
- dated primary evidence;
- a neutral title and summary;
- a short explanatory profile;
- status and status rationale;
- at least one approach, pipeline stage, and data type; and
- matching evidence for any adoption, money, or data-volume figure.

Disclose material financial, employment, advisory, or organizational
connections to an initiative you propose or edit.

## Pull request workflow

1. Keep the change focused.
2. Update or add public sources with exact dates.
3. Run `cd website && npm run verify`.
4. Explain uncertainty or conflicting evidence in the pull request.
5. Respond to editorial or technical review.

Nick Vincent gives final editorial approval. Initiative owners may submit
corrections but do not have pre-publication approval rights.

## Corrections and takedowns

Use the correction or review-request issue form. Identify the page, disputed
material, evidence, and requested outcome. Do not post private or sensitive
information in a public issue.

## Licensing

Contributions to code are accepted under the MIT License. Contributions to
catalog data and written content are accepted under CC BY 4.0.
