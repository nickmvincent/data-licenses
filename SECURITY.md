# Security policy

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/nickmvincent/data-licenses/security/advisories/new)
for a vulnerability that could expose data, alter published content, compromise
the build or deployment process, or create a material risk for visitors.

Do not include secrets, personal data, exploit payloads, or other sensitive
details in a public issue.

For ordinary broken links, factual corrections, accessibility problems, or
content disputes, use the public issue forms instead.

## Supported version

The production branch and its current dependencies are supported. Security
fixes are released through the normal reviewed build and deployment process.
